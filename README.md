LISTA DE TAREAS
Proyecto de una Todo List realizada con HTML y CSS.

📋 Descripción

Esta aplicación permite visualizar una lista de tareas pendientes y marcar las tareas como completadas.

El proyecto está realizado como una práctica de HTML y CSS, aplicando conceptos de estructura semántica, formularios, Flexbox, variables CSS y diseño responsive.

🛠️ Tecnologías utilizadas
HTML
CSS
Flexbox
Variables CSS
Media Queries
📁 Estructura del proyecto
todo-list/
│
├── index.html
└── css/
    └── styles.css
✨ Funcionalidades
Mostrar una lista de tareas pendientes.
Marcar tareas como completadas mediante checkbox.
Mostrar visualmente las tareas completadas con texto tachado.
Formulario para añadir una nueva tarea.
Botones para eliminar tareas completadas y todas las tareas.
Diseño responsive para dispositivos móviles.

Nota: los botones de añadir y eliminar son elementos visuales en esta versión, ya que el proyecto no utiliza JavaScript.

Diseño responsive

La aplicación se adapta a diferentes tamaños de pantalla.

En dispositivos móviles:

El formulario se muestra en columna.
Los botones ocupan todo el ancho disponible.
El contenido mantiene un diseño cómodo y sencillo.
